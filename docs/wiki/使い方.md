## 0. 設計の読み方（0.4）

| 軸 | 触るもの |
|----|----------|
| **個体** | `name` / `arg`（hostname, data-host 等）— 1 スロットずつ |
| **種族** | `wiki-site` など 1 フォーム。中の pkg 列は言語が展開 |
| **運用** | 言語の受理（agent: 無 cmd、無 host ネット量産） |

**前提（ルールではない）:** プログラムは常に「一つの jail 個体」の計画。`(host)/(in-jail)` ブロックは設けない。詳細は [three-axes-isomorphism](three-axes-isomorphism)。

**展開:** hostname の埋め込みや dataset 導出は言語側。利用側 sed や二重 hostname は禁止方向（P02 / #9）。

## 1. 言語の「利用」側（0.3 実装語彙）（User Experience）

ユーザーは以下の構文を使って Jail を定義します。

| 構文 | 意味 |
|------|------|
| `(name "…")` | Jail 名 |
| `(from zfs "pool/ds@snap")` | ZFS スナップショットからクローン |
| `(from thin freebsd-14.3)` | Thin Jail（MVP では TODO） |
| `(option dataset "…")` | クローン先の ZFS dataset |
| `(option network vnet-default)  ; host は量産運用で禁止` | ホストのネットワークを共有 |
| `(arg password)` / `(arg x "default")` | 引数宣言 |
| `(pkg "nginx")` | パッケージインストール |
| `(sysrc "nginx_enable" "YES")` | `/etc/rc.conf` 設定 |
| `(copy src dst)` | ホストのファイルを Jail 内にコピー |
| `(service nginx start)` | サービスの起動 |
| `(volume host jail-path)` | 永続ボリューム（nullfs マウント） |
| `(wiki-site …)` | **種族**フォーム（DokuWiki+Caddy）。展開は言語側 |
| `(pw-group)` `(pw-user)` `(smb-password)` | Samba 等の語彙（cmd 代替） |
| `(template-subst …)` | プレースホルダ置換（sed 禁止） |
| `(cmd …)` | **常用禁止**（agent 不可。0.4 で受理から外す方向） |
| `(workdir …)` | 作業ディレクトリ |

### フェーズ（Phase）

| phase | 内容 |
|-------|------|
| `build`（デフォルト） | 作成・パッケージ投入など |
| `start` | 起動 |
| `stop` | 停止 |
| `destroy` | 破棄 |

フェーズごとに、実行する **効果（effect）** が変わります。

### 最小例

```racket
#lang makejail

(name "web-nginx")
(from zfs "zroot/jails/base@clean")
(option dataset "zroot/jails/web-nginx")
(option network vnet-default)  ; host は量産運用で禁止

(pkg "nginx")
(sysrc "nginx_enable" "YES")
(copy "templates/nginx.conf" "/usr/local/etc/nginx/nginx.conf")
(service nginx start)
```

リポジトリ付属例:

- `examples/nginx.rkt`
- `examples/nginx-thin.rkt`（thin 経路は TODO 表示）

## 2. CLI の使い方（実際の操作）

```bash
# パッケージとしてリンク
raco pkg install --link /path/to/my-makejail-lop

# 効果のプレビュー（どの OS でも安全・デフォルト）
raco makejail plan examples/nginx.rkt

# dry-run（実際には実行しない）
raco makejail build examples/nginx.rkt --dry-run

# FreeBSD で実際に実行
raco makejail build examples/nginx.rkt --apply

# 破棄
raco makejail destroy examples/nginx.rkt --apply

# リモートの FreeBSD で実行（先に makejail パッケージが必要）
raco makejail build examples/nginx.rkt --apply root@freebsd.local
```

| フラグ | 意味 |
|--------|------|
| `--dry-run` | 効果列のみ（既定に近い安全側） |
| `--apply` | FreeBSD 上で実コマンド実行 |
| `--phase build\|start\|stop\|destroy` | フェーズ指定 |

テスト:

```bash
raco test test/dsl-test.rkt
```

## 3. 注意点（MVP プロトタイプ）

このバージョンは **Grok-order MVP プロトタイプ** であり、以下は **TODO / 凍結** です。

| 項目 | 状態 |
|------|------|
| Thin Jail の自動化 | TODO |
| NAT / port expose | 未実装（偽成功にしない） |
| VNET | 複雑化は凍結。量産用 thin-vnet は [Issue #3](https://github.com/bluehive/my-makejail-lop/issues/3) で仕様のみ |
| 引数のコンパイル時チェック強化 | 今後 |
| AppJail 完全互換 | **非目標** |

本番の AppJail 互換ではなく、あくまで **「ドメインを言語化する」実験台** です。

実実行（`--apply`）は **FreeBSD + root 相当 + ZFS/jail** が前提です。Linux などでは `plan` / dry-run のみ使ってください。
